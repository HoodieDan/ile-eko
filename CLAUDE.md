# CLAUDE.md

Guidance for working in the Ilé Èkó monorepo.

## Sources of truth

- **Start with the `docs/` folder.** Before researching anywhere else, consult the resources in `docs/` as the first source of truth. They are our easy, canonical starting point for how things are meant to work — treat them as the default reference and build from there.
- **The docs are a starting point, not gospel.** The resources in `docs/` are not always correct or complete. Use them to orient yourself, then verify against the actual code and extend from there.
- **For AI-related features, also check the Tempo project.** When working on any of the app's AI features, look in the Tempo project — located outside this repo at `~/Documents/Projects/Tempo` (i.e. `../../Tempo` relative to this repo root) — to see how a similar feature was already implemented, and use that as a reference for your approach.
